# QCE'26 MLIR Tutorial Website

This repository contains the standalone website for the QCE'26 tutorial
[*MLIR for Quantum-Classical Compilation: Building a Future-Proof Compilation Framework*](index.html).
The site is a minimal, single-page presentation of the tutorial abstract,
schedule, and organizers, designed for GitHub Pages deployment with plain HTML5
and a single CSS file.

The tutorial content is based on the proposal material in `main.tex` and points
to the broader Munich Quantum Toolkit effort. To preview locally, either open
`index.html` directly or run:

```bash
python3 -m http.server --directory website 8000
```

Then visit `http://localhost:8000`.
